# Janus Rebrand Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rename the app from "kanban-postit" to "Janus" across the browser tab, package metadata, sidebar, and login page, using the final transparent icon asset from the design handoff (`public/janus-icon.png`, already copied in) and a faithful React recreation of the handoff's logo entrance animation, used on the login page.

**Architecture:** Metadata/JSX swaps (title, package name, sidebar) plus one new self-contained animated component (`JanusLogoReveal`) built with plain `useState`/`useEffect`/CSS transitions — no animation library, consistent with how the rest of this codebase animates things (CSS `@keyframes` in `globals.css`, Tailwind `transition-*` utilities). No new dependencies beyond a Google Font.

**Tech Stack:** Next.js App Router `Metadata` API, `next/font/google` (Archivo), CSS transitions/keyframes, existing Tailwind utility classes.

**Assets already in place** (done during brainstorming, commit pending): `public/janus-icon.png` (transparent, final), `app/favicon.ico` (regenerated from it).

- [ ] **Step 2: Write the component**

```tsx
// src/modules/ui/JanusLogoReveal.tsx
'use client';

import { useEffect, useState } from 'react';

export function JanusLogoReveal({
  wordmark = 'JANUS',
  iconSize = 380,
  entranceSpeed = 900,
  idleFloat = true,
  sheenEffect = true,
}: {
  wordmark?: string;
  iconSize?: number;
  entranceSpeed?: number;
  idleFloat?: boolean;
  sheenEffect?: boolean;
}) {
  const [iconIn, setIconIn] = useState(false);
  const [textIn, setTextIn] = useState(false);

  useEffect(() => {
    const t1 = setTimeout(() => setIconIn(true), 120);
    const t2 = setTimeout(() => setTextIn(true), 120 + entranceSpeed * 0.55);
    return () => {
      clearTimeout(t1);
      clearTimeout(t2);
    };
  }, [entranceSpeed]);

  const letters = wordmark.split('');
  const wordmarkFontSize = (76 / 380) * iconSize;

  return (
    <div className="flex flex-col items-center" style={{ gap: iconSize * (36 / 380) }}>
      <div
        className="relative overflow-hidden rounded-[18px]"
        style={{ width: iconSize }}
      >
        <img
          src="/janus-icon.png"
          alt="Janus"
          className="block w-full"
          style={{
            opacity: iconIn ? 1 : 0,
            transform: iconIn ? 'scale(1) rotate(0deg)' : 'scale(0.7) rotate(-10deg)',
            transformOrigin: 'center bottom',
            transition: 'opacity 1000ms cubic-bezier(0.16,1,0.3,1), transform 1200ms cubic-bezier(0.16,1,0.3,1)',
            animation: idleFloat ? 'janus-float 5s ease-in-out infinite 1.4s' : 'none',
          }}
        />
        {sheenEffect && (
          <div
            className="pointer-events-none absolute inset-0"
            style={{
              background: 'linear-gradient(100deg, transparent 40%, rgba(255,255,255,0.85) 50%, transparent 60%)',
              mixBlendMode: 'screen',
              animation: 'janus-sheen 3.2s ease-in-out infinite 1.6s',
            }}
          />
        )}
      </div>
      <div className="flex" style={{ gap: '0.06em' }}>
        {letters.map((char, i) => (
          <span
            key={`${char}-${i}`}
            className="font-archivo inline-block font-extrabold"
            style={{
              fontSize: wordmarkFontSize,
              letterSpacing: '0.02em',
              color: 'oklch(0.28 0.06 265)',
              opacity: textIn ? 1 : 0,
              transform: textIn ? 'translateY(0)' : 'translateY(18px)',
              transition: `opacity 620ms cubic-bezier(0.16,1,0.3,1) ${i * 60}ms, transform 700ms cubic-bezier(0.16,1,0.3,1) ${i * 60}ms`,
            }}
          >
            {char}
          </span>
        ))}
      </div>
    </div>
  );
}
```
