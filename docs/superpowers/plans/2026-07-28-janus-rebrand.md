# Janus Rebrand Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rename the app from "kanban-postit" to "Janus" across the browser tab, package metadata, sidebar, and login page, using the cube-icon logo already cropped into `public/janus-icon-512.png` and `app/favicon.ico`.

**Architecture:** Pure metadata/JSX text-and-image swaps — no new components, no data model changes, no new dependencies. The logo asset and favicon were already generated during brainstorming (commit `c3f16e6`) and just need to be referenced from three existing files.

**Tech Stack:** Next.js App Router `Metadata` API, plain `<img>` tag (the icon is a small static asset, not worth Next's `<Image>` component for a 24-32px icon), existing Tailwind utility classes.
